# Hero Association

An open-source game-management platform where players run hero agencies,
recruit and equip heroes, send parties on quests, and manage their growth.
The project currently includes a React frontend, Quarkus backend services,
Keycloak authentication, PostgreSQL, Docker Compose, and browser end-to-end
tests. It is in the early stages of development.
